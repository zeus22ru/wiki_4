# Brag Plan: БочкарИИ

## What is this app?
БочкарИИ — локальный RAG-ассистент: вопрос по внутренней документации → проверяемый ответ с цитатами, плюс база знаний и интеграции.

## The angle
Монтажный хаос «где инструкция?» схлопывается в реальный UI. Динамика через hard cuts, snap zoom, whip, короткий glitch — не через тряску. Каждый удар ведёт к конкретной функции.

## Hook (first 2-3 seconds)
Визуальный хаос PDF / DOCX / таблиц / wiki + крупно «ГДЕ ЭТА ИНСТРУКЦИЯ?»

## Key moments (the middle)
- Reveal UI «БочкарИИ» + «СПРОСИ У БАЗЫ ЗНАНИЙ»
- Вопрос «Как настроить принтер на ТСД?» → фрагмент ответа
- Источники и цитаты
- Загрузка / база знаний
- TELEGRAM + БИТРИКС24
- Финал: бренд + github

## Outro / punchline
«БОЧКАРИИ» / «ТВОИ ДОКУМЕНТЫ. ОТВЕТЫ ПО ДЕЛУ» + github.com/zeus22ru/wiki_4

## User flow worth showing
Хаос документов → интерфейс → вопрос → ответ → источники → база → каналы → бренд

## Tone
- Preset: chaotic
- Creative direction: максимально динамично, дёрганые склейки 80–180 мс, whip / snap zoom / punch / короткий glitch
- Interpretation: удар → рывок → читаемый кадр 0.8–1.2 с для подписи / 1.5–2.5 с для ключевых экранов → следующий удар; без dissolve и постоянной тряски

## Format: landscape — 1920x1080
## Duration: 22 seconds

## Visual identity (from the project)
- Background: #F4F5F6 (canvas) / #1a1d21 (dark accents) / #000 on blackouts
- Accent: #A88656
- Text: #212529 / #e8eaed / white on dark punches
- Display font: Inter Black / ExtraBold
- Body font: Inter
- Strongest visual: workspace shell, empty tiles, sources panel, gold brand

## Share copy (draft)
ГДЕ ЭТА ИНСТРУКЦИЯ? БочкарИИ — спроси у базы знаний: ответ с источниками, не с потолка. github.com/zeus22ru/wiki_4

## Audio direction
- Role: dense rhythmic layer
- Music: happy-beats-business-moves-vol-1 (bundled ~120 BPM — ближайший энергичный трек; целевой 145–165 недоступен в бандле)
- Music treatment: старт сразу, громко, fade out на финале ~0.4s; склейки к сильным долям
- Music cue guidance: preset cues/happy-beats-business-moves-vol-1; strong cues ~17.02, 18.02, 20.02, 23.02 для финала/акцентов
- Audio-reactive treatment: subtle; лёгкий punch scale на бас у финального логотипа
- SFX posture: dense на склейках — whoosh, click, glitch, impact; не дублировать каждый кадр
- Audio-coupled moments: хаос-склейки 0–3; reveal 3–6; send click 6–10; sources snap 10–14; docs burst 14–17; integration hits 17–19; logo impact 19–22
- Restraint rule: без диктора; без постоянного glitch-шума

## Storyboard

### Scene 1 — Chaos hook — 3.0s
PDF/DOCX/таблицы/wiki flash каждые 0.25–0.5с; крупно «ГДЕ ЭТА ИНСТРУКЦИЯ?»
Sequential/interaction: yes — document cards slam one by one then cut
Audio intent: ударный старт
Audio-coupled idea: impact + glitch на склейках
Transition mood: hard flash → Scene 2

### Scene 2 — UI reveal — 3.0s
Документы схлопываются в UI БочкарИИ; «СПРОСИ У БАЗЫ ЗНАНИЙ»
Sequential/interaction: yes — cards collapse inward, brand punch-in
Audio intent: whoosh → impact
Transition mood: snap zoom → Scene 3

### Scene 3 — Q→A — 4.0s
Поле вопроса с «Как настроить принтер на ТСД?» → ответ; зум на фрагмент; «ВОПРОС → ИНСТРУКЦИЯ»
Sequential/interaction: yes — type/send simulation then answer reveal
Audio intent: clicks + soft whoosh
Transition mood: whip / hard cut → Scene 4

### Scene 4 — Sources — 4.0s
Источники и цитаты; связь ответа с документом; «С ИСТОЧНИКАМИ»
Sequential/interaction: yes — source cards snap in sequence
Audio intent: click snaps
Transition mood: hard cut → Scene 5

### Scene 5 — Knowledge base — 3.0s
Загрузка документов / управление базой; «ДОКУМЕНТЫ → ЗНАНИЯ»
Sequential/interaction: yes — upload chip + list punch
Audio intent: whoosh + click
Transition mood: hard cut → Scene 6

### Scene 6 — Integrations — 2.0s
Два акцента: TELEGRAM, БИТРИКС24
Sequential/interaction: yes — two cards, one after another (~1s each)
Audio intent: dual impacts
Transition mood: flash → Scene 7

### Scene 7 — Outro — 3.0s
Крупно БОЧКАРИИ; «ТВОИ ДОКУМЕНТЫ. ОТВЕТЫ ПО ДЕЛУ»; github.com/zeus22ru/wiki_4; hold for read
Sequential/interaction: none — hold
Audio intent: strongest impact + music fade
Transition mood: cut to black

**Music mood for this video:** chaotic / energetic electronic bed
**Audio summary:** Dense beat with cut-synced SFX; logo lands on a strong beat; no VO.
